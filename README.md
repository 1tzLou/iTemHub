iTemHub

Web-Based School Item Borrowing and Lost-and-Found Management System

iTemHub is an academic capstone project designed to help students and school personnel manage school item borrowing and lost-and-found reports through a centralized web-based platform.

The project aims to make item tracking more organized, improve record management, and provide an easier way to monitor borrowed, returned, lost, and found items within the school.

Project Objectives

- Record school items, borrowers, and lost-and-found reports.
- Monitor borrowing and return transactions.
- Track the status of lost and found items.
- Maintain organized and accessible item records.
- Generate reports summarizing borrowing, returns, and lost-and-found activities.

Current Features

- Clickable HTML prototype.
- Initial user interface and navigation flow.
- Proposed system layout and user interaction design.

Note: The project is currently under development. Not all proposed features are fully implemented.
